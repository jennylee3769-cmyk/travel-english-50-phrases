# ✈️ 해외여행 필수 영어회화 50문장

해외여행에서 바로 쓰는 영어 회화 50문장 랜딩 페이지입니다. 공항·입국심사부터 기내, 택시, 호텔, 식당, 쇼핑, 사진 부탁, 긴급 상황까지 여행 동선 순서로 8묶음으로 정리했습니다.

- 각 문장 카드: **영어 문장**(크게) · **한국어 뜻** · **한글 발음 표기**
- 카드의 **복사** 버튼을 누르면 세 줄이 그대로 복사됩니다.
- 상단 칩 메뉴로 상황별 바로 이동, 휴대폰 화면(390px) 기준으로 읽기 좋게 만들었습니다.

## 문장을 고치고 싶을 때

`build.py`의 문장 세 값만 바꾸고 다시 실행하면 됩니다.

```
python3 build.py
```

| 파일 | 설명 |
| --- | --- |
| `site/index.html` | 실제 배포되는 페이지 (이 파일 하나로 동작) |
| `build.py` | 페이지 생성기 (문장·디자인·스크립트) |
| `문장_50.md` | 50문장 검수용 목록 |
| `sentences.json` | 문장 데이터(JSON) |

## 배포

Vercel에 정적 사이트로 배포되어 있으며, 이 저장소의 `main` 브랜치가 바뀌면 자동으로 다시 배포됩니다.
